# Recommended Clean Nginx Structure

## `sites-available/` and `sites-enabled/`

Used for full site configurations:

-   `nginxgolmolab.duckdns.org`
-   `app-backend`
-   future virtual hosts

------------------------------------------------------------------------

## `conf.d/`

Used for shared configuration snippets:

-   `security-headers.conf`
-   `proxy-common.conf`
-   `gzip.conf`
-   `real-ip.conf`
-   `rate-limit.conf`
-   `upstreams.conf`

------------------------------------------------------------------------

# What Goes in `conf.d` for the Current Project

## 1. Common Proxy Headers

`/etc/nginx/conf.d/proxy-common.conf`

``` nginx
proxy_set_header Host $host;
proxy_set_header X-Real-IP $remote_addr;
proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
proxy_set_header X-Forwarded-Proto $scheme;
proxy_http_version 1.1;
proxy_set_header Connection "";
```

Example usage in the frontend vhost:

``` nginx
location / {
    proxy_pass http://127.0.0.1:6081;
    include /etc/nginx/conf.d/proxy-common.conf;
}
```

------------------------------------------------------------------------

## 2. Security Headers

`/etc/nginx/conf.d/security-headers.conf`

``` nginx
add_header X-Frame-Options "SAMEORIGIN" always;
add_header X-Content-Type-Options "nosniff" always;
add_header Referrer-Policy "strict-origin-when-cross-origin" always;
add_header X-XSS-Protection "1; mode=block" always;
```

Example usage in the TLS vhost:

``` nginx
include /etc/nginx/conf.d/security-headers.conf;
```

------------------------------------------------------------------------

## 3. Compression

`/etc/nginx/conf.d/gzip.conf`

``` nginx
gzip on;
gzip_vary on;
gzip_proxied any;
gzip_comp_level 5;
gzip_types
    text/plain
    text/css
    text/xml
    application/json
    application/javascript
    application/xml+rss
    application/xml
    image/svg+xml;
```

------------------------------------------------------------------------

## 4. Basic Rate Limiting

`/etc/nginx/conf.d/rate-limit.conf`

``` nginx
limit_req_zone $binary_remote_addr zone=perip:10m rate=10r/s;
```

Example usage in the frontend:

``` nginx
location / {
    limit_req zone=perip burst=20 nodelay;
    proxy_pass http://127.0.0.1:6081;
    include /etc/nginx/conf.d/proxy-common.conf;
}
```

------------------------------------------------------------------------

# What Should NOT Go in `conf.d`

Avoid placing the following there:

-   Old `server { ... }` blocks from testing
-   Configurations specific to a single application when `sites-enabled`
    is already used
-   Duplicated `80/443` server configurations
-   Historical junk generated by Certbot

------------------------------------------------------------------------

# Practical Conclusion

For this setup:

-   Domain reverse proxy → `sites-available/nginxgolmolab.duckdns.org`
-   Backend application → `sites-available/app-backend`
-   Reusable snippets (proxy headers, security headers, compression,
    limits) → `conf.d/`

**Summary**

-   `conf.d` → reusable configuration pieces
-   `sites-*` → complete virtual hosts
